4. Theory:

Quick Sort is an efficient, divide-and-conquer, in-place sorting algorithm. It works by selecting a 'pivot' element from the array and partitioning the other elements into two sub-arrays according to whether they are less than or greater than the pivot.

Working of Quick Sort:

  • Divide: Select a pivot element from the array.
  • Partition: Rearrange elements so that all elements smaller than the pivot come before it, and all larger elements come after it.
  • Conquer: Recursively apply the above steps to the sub-arrays.

5. Time and Space Complexity:

6. Algorithm & Pseudocode:

ALGORITHM QuickSort(arr, low, high)
1. if low < high then
2.     pivotIndex ← Partition(arr, low, high)
3.     QuickSort(arr, low, pivotIndex - 1)
4.     QuickSort(arr, pivotIndex + 1, high)
5. end if
END ALGORITHM

ALGORITHM Partition(arr, low, high)
1. pivot ← arr[high]
2. i ← low - 1
3. for j ← low to high - 1 do
4.     if arr[j] ≤ pivot then
5.         i ← i + 1
6.         SWAP(arr[i], arr[j])
7.     end if
8. end for
9. SWAP(arr[i + 1], arr[high])
10. return (i + 1)
END ALGORITHM
