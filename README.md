## 📂 Summary of Assignments

### 1. [Assignment 1: Merge Sort](./Assignment_1_Merge_Sort/)
- **Topic:** Sorting customer order timestamps using Divide and Conquer Merge Sort.
- **Key Concepts:** $O(n \log n)$ time complexity, stable sorting, recursion tree analysis.
- **Code:** [`merge_sort.cpp`](./Assignment_1_Merge_Sort/merge_sort.cpp)
- **Documentation:** [`Assignment_1_Merge_Sort.md`](./Assignment_1_Merge_Sort/Assignment_1_Merge_Sort.md)

---

### 2. [Assignment 2: Quick Sort](./Assignment_2_Quick_Sort/)
- **Topic:** StreamFlix Movie Recommendation System sorting movies by IMDb rating.
- **Key Concepts:** Lomuto Partitioning, pivot selection strategies, in-place sorting, $O(n \log n)$ average time complexity.
- **Code:** [`quick_sort.cpp`](./Assignment_2_Quick_Sort/quick_sort.cpp)
- **Documentation:** [`Assignment_2_Quick_Sort.md`](./Assignment_2_Quick_Sort/Assignment_2_Quick_Sort.md)

---

### 3. [Assignment 3: Fractional Knapsack](./Assignment_3_Fractional_Knapsack/)
- **Topic:** Emergency Relief Supply Distribution using Greedy Fractional Knapsack algorithm.
- **Key Concepts:** Value-to-Weight ratio greedy strategy, optimal substructure, partial selection for maximum utility ($O(n \log n)$).
- **Code:** [`fractional_knapsack.cpp`](./Assignment_3_Fractional_Knapsack/fractional_knapsack.cpp)
- **Documentation:** [`Assignment_3_Fractional_Knapsack.md`](./Assignment_3_Fractional_Knapsack/Assignment_3_Fractional_Knapsack.md)

## 🚀 How to Run the Programs

You can compile and run any of the C++ code files using `g++`:

### Assignment 1: Merge Sort
```bash
g++ -std=c++11 Assignment_1_Merge_Sort/merge_sort.cpp -o merge_sort
./merge_sort
```

### Assignment 2: Quick Sort
```bash

./quick_sort
```

### Assignment 3: Fractional Knapsack
